# 3D world task — exact interface
Own only dist/world.mjs. Parent owns scene engine, renderer/events, HTML/CSS and vendoring Three. No other file edits, browser, remote writes or subagents. Read docs/room04/design.md for intent.

Create beautiful original low-poly 3D dioramas for all six chapters using only Three primitives. The user's Sketchfab originals cannot be downloaded unauthenticated; custom geometry must not be represented as downloaded assets. Sources are available separately in credits. No external network, no text-heavy UI.

Export buildWorld(THREE, view), where view = {chapter:0..5,step:number,phase:string,activeAction:string,letterFound:boolean}. Return:
{root:THREE.Group, targets:[{id:string,label:string,object:THREE.Object3D,anchor?:THREE.Vector3}], camera:{position:[x,y,z],target:[x,y,z],width:number,height:number}, background:number, update:(elapsedSeconds,dtSeconds,{reducedMotion:boolean})=>void, dispose:()=>void}
Object targets can be parent Groups; parent raycasts their descendants. anchor is WORLD position for accessible hotspot projection; if absent parent gets object's world position. Mark all target child meshes by descendant parent search; no private globals. IDs must match exact activeAction contract. Include available optional target IDs. Targets should be visible/reachable at appropriate steps (not all target names at all times). Parent will make them focusable and add subtle glints, so don't add instruction labels. You can draw diegetic ROOM04 card/number/label via CanvasTexture (document is available at runtime); blank tasteful paper otherwise. No document at module import time (tests may import). Dispose geometries/materials/textures and scene-specific lights owned by world.

General art direction: wide sky, luminous green grass, pale butter/peach house, cornflower-blue chair with tiny white nick, terra-cotta/white/lilac pots with flowers, oversized cotton clouds, ordinary objects in impossible places. 3D editorial toy-like, sunlight, soft contact shadows (parent will configure renderer shadows and shared hemisphere + directional lighting). Target ~100-250 meshes per scene, reuse materials/geometries where possible. Avoid huge busy fields, hard black outlines, horror shadows, eyes/faces. Ground may be rounded rectangular floating turf on sky, gentle broad landscape rings. World origin near center, typical ground 12x8. Camera orthographic 12,10,16 look at0,1,0 and frame width18,height12. Parent fits screen and can slowly move camera. All states should be attractive, uncluttered, enough object size for touch. Do not add text plates other than story's card/house number/label.
